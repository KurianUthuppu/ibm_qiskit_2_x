# 🧪 IBM Qiskit 2.X Practice Exam — C1000-179

Welcome to the **Qiskit Practice Exam Repository** — a curated set of practice questions and resources designed to help you prepare for the **IBM Certified Quantum Computational Scientist** exam _(C1000-179: Fundamentals of Quantum Computing Using Qiskit v2.X Developer)_.

---

## 🎯 Certification Overview

An **IBM Certified Quantum Computational Scientist** is an individual who:

- Possesses fundamental knowledge of **quantum computing concepts**.
- Demonstrates skills using the **Qiskit SDK** and **Qiskit Runtime**.
- Can create and execute quantum programs in **Python** on IBM Quantum systems.
