# IBM Qiskit 2.X

A learning repository for quantum computing with **Qiskit 2.X**, exploring new features, key concepts, and exam preparation.

## What's Inside

### Practice Exams

Preparation material for the **IBM Certified Associate Developer — Quantum Computation using Qiskit v2.X** exam (C1000-179). Includes practice questions with detailed solutions. See the [practice exams README](practice_exams/README.md) for the full breakdown.

### Lab

Hands-on notebooks exploring key quantum computing concepts:

- **Magic States** — fault-tolerant quantum computing, Eastin-Knill theorem, gate teleportation, and magic state distillation

### Qiskit Release Features

Notebooks highlighting interesting features from Qiskit releases (In-Pipeline)

## Prerequisites

- Python 3.9+
- [Qiskit](https://github.com/Qiskit/qiskit) 2.x
- [Qiskit IBM Runtime](https://github.com/Qiskit/qiskit-ibm-runtime)
- An [IBM Quantum](https://quantum.ibm.com/) account (for running on real hardware)
